What is PitcherPro

PitcherPro is a VS Code extension designed to help developers keep project documentation aligned with their current workspace — without starting from a blank file, and without maintaining it by hand.

FAQ

Questions, answered.

What is PitcherPro?
A VS Code extension that creates and keeps your project's README aligned with your actual workspace, automatically.
Is PitcherPro free?
Yes — PitcherPro is free to install from the VS Code Marketplace.
Which editors are supported?
PitcherPro currently supports Visual Studio Code.
Which technologies are supported?
PitcherPro can detect a range of common languages and frameworks, including JavaScript, TypeScript, React, Vue, Node.js, Python, and more. Coverage continues to expand.
Does PitcherPro modify my source code?
No. PitcherPro only reads your workspace to generate and update your README — it does not modify your source files.
Can I use it on an existing project?
Yes. PitcherPro works with existing projects and existing README files, not just new ones.
Can I use it for open-source projects?
Yes — it's a natural fit for repositories where contributors are regularly changing project structure.
How do I install PitcherPro?
Search for "PitcherPro" in the VS Code Extensions panel, or install it directly from the VS Code Marketplace.
